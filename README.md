# Olívia 15

Protótipo da experiência digital para a festa de 15 anos da Olívia.

## Estado

A versão atual é uma proposta inicial de interface para avaliação da Patrícia e da Olívia. O visual, os textos, as cores, as fotos e a estrutura final serão definidos por elas.

## Desenvolvimento

A página está sendo construída inicialmente em HTML, CSS e JavaScript puros, com foco em publicação simples pelo GitHub Pages e evolução rápida durante a fase de validação.

## Publicação

O conteúdo da branch `master` pode ser publicado pelo GitHub Pages.
